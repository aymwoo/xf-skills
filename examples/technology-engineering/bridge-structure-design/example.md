# 案例：桁架桥梁结构设计与承重试验 (Example Case)

本案例完整展示高中通用技术（技术与工程）学科在普通高中地质版课程背景下，使用 Teaching Skills Framework 生成工程实施方案与表现性评价量规的真实输入与输出对照。

## 1. 教学背景与学情研判 (Context)

### 课程地位
本课是通用技术“结构与设计”的核心实践课，要求学生综合运用受拉、受压、受弯等受力分析知识，体验工程权衡与试验测试。

### 核心工程矛盾
- **自重与强度矛盾**：自重越轻得分越高，但过度减重会导致杆件压杆失稳。
- **节点连接强度**：手工胶接易出现虚粘或偏心受拉，需设计规范节点搭接工艺。

## 3. 生成产物一：《桁架桥梁结构设计与承重试验》教学实施方案

### 一、工程挑战与技术指标
- **跨度要求**：400mm 净跨
- **重量限制**：桥体自重 $\le 60\text{g}$
- **承重要求**：跨中挂载加载点，承受不小于 $10\text{kg}$ 的静态垂直载荷
- **性能指数**：$K = \frac{\text{极限载荷}(\text{g})}{\text{结构自重}(\text{g})}$

### 二、工程设计与实施流程
1. **方案构思与三视图绘制 (25分钟)**：
   - 各组绘制 1:1 正比例侧立面桁架草图。
   - 分析上弦杆（受压）、下弦杆（受拉）与腹杆（交替受拉/压）的力流传递路径。
2. **加工与装配工艺 (35分钟)**：
   - 使用卡尺下料，两片主桁架在图纸上垫保鲜膜压平胶接。
   - 使用横撑将两片桁架连接为空间整体三维桁架箱梁。
3. **技术试验与破坏性测试 (20分钟)**：
   - 采用水桶注水法进行连续加载，记录破坏瞬间载荷与首个折断构件部位。
4. **失效分析与迭代设计 (10分钟)**：
   - 分析压杆欧拉临界力 $P_{cr} = \frac{\pi^2 E I}{L^2}$，提出将长受压杆缩短或改为空心多边形截面的优化建议。
