# 案例：电子电路手工五步焊接工艺实训

## 1. 输入数据 (Input)
```yaml
practice_skill: 印刷电路板 (PCB) 直插元件手工电烙铁焊接
tools_and_equipment: 内热式电烙铁 (30W)、焊锡丝、松香助焊剂、斜口钳、PCB 练习板、万用表
inspection_standard: 焊点呈光滑圆锥火山状、焊锡浸润良好、无虚焊假焊、无相邻引脚桥接连锡
```

## 2. 成果展示
- **五步焊接法口诀**：
  1. 准备施焊（烙铁头清洁挂锡）；
  2. 加热焊件（烙铁同时接触引脚与焊盘）；
  3. 送入焊丝（从烙铁对面送入焊锡）；
  4. 移开焊丝（焊锡充足后先撤焊丝）；
  5. 移开烙铁（45度角迅速撤离烙铁）。
- **安全防范红线**：禁止手摸烙铁金属管部；烙铁不用时必须放置在专用金属烙铁架内；焊接完毕必须洗手。
- **质检与排错**：用万用表蜂鸣档排查相邻管脚是否存在短路；使用吸锡器修正桥接不良焊点。
