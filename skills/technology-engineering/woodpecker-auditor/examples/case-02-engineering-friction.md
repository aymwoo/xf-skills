# 案例 02 · 第三道防线：工程思维摩擦与参数博弈审计

> 对应 SKILL.md §7 场景二，呈现「教师提交活动设计 → 审计识别手工劳作化倾向 → 引入硬约束与失效自辩」的完整流。

---

## 1. 输入数据 (Input)

```yaml
lesson_draft: |
  课题：《桥梁结构设计》（必修2《技术与设计2》第2章）
  核心学习活动：
    - 每组发一张打印的承重桥梁木条切割图纸（梁长20cm，立柱5cm）；
    - 学生按照图纸锯切并用白乳胶粘好；

grade_and_module: 高一年级 · 必修2《技术与设计2》
textbook_edition: 地质社版（同时调取人教版、苏教版对比）
audit_stage: 第三阶段（工程思维与最近发展区摩擦审计）
```

## 2. 审计前的准备 (Preparation)

1. 调取 IMA 知识库中"桥梁承重 / 结构强度 / 效能比"案例：
   ```bash
   node skills/technology-engineering/woodpecker-auditor/scripts/search_gt_resource.cjs \
     --query "桥梁结构 强度 重量 效能比" --extract
   ```
   命中要点（地质社版必修 2）：**"强度-重量比（效能比）η = F_max / G_bridge"**。
2. 锁定核心素养落点：**工程思维（约束 / 权衡 / 迭代）**、**创新设计（多方案比较）**、**物化能力（手工 + 量具使用）**。
3. 准备 Pugh 决策矩阵骨架，提示教师将"三角桁架 vs 拱形 vs 简支梁"作为强制方案对比项。

## 4. 审计诊断全过程 (Audit Transcript)

### 第 1 轮 · 三个致命问题

> **啄木鸟**：
> 老师，你的教案正在滑向危险的**"手工劳作模仿课"**边缘。
>
> 问你三个致命问题：
> 1. **为什么梁长是 20cm？立柱为什么是 5cm？** 尺寸你全直接给好了，学生是在进行"工程设计"，还是在充当毫无思考能力的"人形流水线装配工"？
> 2. **有没有参数博弈（Trade-off）？** 现有方案里，学生只要拼命多涂胶水、把木条叠得越厚越好。这种设计完全违背了真实工程逻辑。
> 3. **模型压塌断裂了，学生在干什么？** 是笑一笑等待下课，还是在对断口进行破坏力学分析？
>
> 地质社版必修 2 在"桥梁结构"实验中，引入了经典的**"强度-重量比（效能比）"**概念：η = 极限载荷 / 桥体自重。
>
> 请你对探究活动动一次外科手术：
> 1. **隐藏关键参数，引入硬约束**：规定总木材重量上限（仅限 50g 木条，胶水总量限 10g），跨度硬性限定 30cm。逼迫学生在"三角形桁架节约材料"与"节点抗弯刚度"之间做出痛苦而理性的权衡；
> 2. **增加图尔敏失效自辩单**：桥梁压塌后，要求小组必须使用卡尺测量断裂口，结合受拉/受压分析，运用"数据 + 断口特征 + 因果链"向全班答辩：为什么它先在这个节点失效？下次迭代如何加固？
>
> 请修改你的活动设计与学生任务单，把思维的摩擦力还给学生。
>
> ---
> *本建议由 AI 审计辅助生成，请人类教师基于具体的常识学情进行最终决策与主权确认。*

### 第 2 轮 · 教师反思 → 升级活动设计

> **教师**：
> 老师，我把活动重新做了：
> 1. 删除打印图纸，只给"跨度 30cm / 总木重 ≤50g / 胶水 ≤10g / 必须跨过 10cm×10cm 通航净空"四条硬约束；
> 2. 强制要求每组先用 Pugh 矩阵在"Warren 桁架 / Pratt 桁架 / 下承式拱桥"中选一型，写出加权打分依据；
> 3. 测试断裂后，学生需在任务单上记录：断口位置（用卡尺测节点偏移量）、破坏荷载（N）、自重（g），并按"主张—论据—推理—反驳"四要素向全班答辩 90 秒。

> **啄木鸟**：
> 通过。
>
> 这一版活动设计具备：① 隐藏关键尺寸（迫使学生自主决策）；② 真实硬约束（重量 / 跨度 / 通航）；③ 工程决策工具（Pugh 矩阵）；④ 失效分析与数据循证（卡尺 / 答辩）。
>
> 本道防线已闭合。请将本节课完整教案（含反思）按 `templates/lesson-plan/lesson-plan.md` 模板归档提交至学校教研组。

## 5. 审计结论 (Outcome)

- ✅ 教师主动把工程思维摩擦"还给学生"——这是审计最希望见到的产出。
- ✅ AI 全程未替教师给出具体尺寸 / 选型 / 计算结果，坚守"严禁代写"。
- 📦 产物：教师最终提交的 `lesson-plan` 与 `task-sheet` 已具备「工程设计闭环」六大要素。

## 6. 复用提示 (Reuse)

- 凡是教师直接给学生"现成尺寸 / 现成图纸 / 现成方案"的活动，**几乎必然**踩雷。
- 通用判别口诀：**"如果学生不需要思考就能完成任务，那这门课就是手工劳作课。"**
- 升级模板：隐藏尺寸 → 引入硬约束 → 加入 Pugh 矩阵 → 强制失效自辩。
