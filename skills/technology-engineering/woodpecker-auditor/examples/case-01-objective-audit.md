# 案例 01 · 第一道防线：捕获"大词虚化"目标审计

> 对应 SKILL.md §7 场景一，完整呈现「教师提交 → 审计诊断 → 教师重写 → 通过」的最小闭环。

## 1. 输入数据 (Input)

```yaml
lesson_draft: |
  课题：《闭环控制系统》（选择性必修1《电子控制技术》模块）
  教学目标：
    1. 培养学生的技术意识与工程素养；
    2. 提高动手制作能力，体验传感器控制的乐趣；
    3. 掌握闭环控制的基本工作过程。
grade_and_module: 高一年级 · 选择性必修1《电子控制技术》第3章
textbook_edition: 苏教版（同时使用人教版做参数对比）
audit_stage: 第一阶段（目标可测审计）
```

## 2. 审计前的准备 (Preparation)

1. 锁定本节所属课标学业质量水平 → **水平 3：能通过方框图表达闭环系统的反馈通道，并能通过测定物理量的偏差量分析干扰对输出的影响**。
2. 调取 IMA 知识库中苏教版与人教版关于"闭环控制测定"的对比案例：
   ```bash
   node skills/technology-engineering/woodpecker-auditor/scripts/search_gt_resource.cjs \
     --query "闭环控制 干扰 被控量" --extract --format markdown
   ```
   命中要点（苏教版）："针对具体控制对象（如温控水箱），测定给定值与被控量差值"。
3. 锁定核心素养落点：**工程思维（约束 / 权衡 / 迭代）**、**图样表达（方框图）**、**物化能力（传感器 + 控制器）**。

## 3. 审计诊断全过程 (Audit Transcript)

### 第 1 轮 · 冻结后续环节 + 指出目标虚化

> **啄木鸟**：
> 老师，请停一下。你的第一步防线直接失守了。
>
> 仔细审视你写的目标——"培养工程素养"、"提高动手能力"、"体验乐趣"，这些词漂亮但空洞。走出这间教室，你用什么证据向评委和自己证明这 40 分钟里学生的"工程素养"提升了？学生插好一根杜邦线就算动手能力提高了？
>
> 翻开课标学业质量水平 3，关于控制系统的核心行为表现是：**"能通过方框图表达闭环系统的反馈通道，并能通过测定物理量的偏差量分析干扰对输出的影响"**。
>
> 我在 IMA【技术与工程教学】知识库中对比了人教版与苏教版：苏教版在此处明确要求学生针对具体控制对象（如温控水箱），测定"给定值与被控量差值"。
>
> 现在，请你拿回笔，把这 3 条目标全部推倒重写：
> 1. 剔除所有无法观测的形容词与虚词，换成具有工程测量意义的行为动词（测定、绘制方框图、量化因果自辩）；
> 2. 为你的闭环控制任务增加一个**明确的物理量指标**（例如：在受外界干扰下，系统在多少秒内将温度稳定在目标值 ±1℃ 的误差范围内）。
>
> 在你的目标重写合格之前，我们暂不讨论后面的教学环节。
>
> ---
> *本建议由 AI 审计辅助生成，请人类教师基于具体的常识学情进行最终决策与主权确认。*

### 第 2 轮 · 教师重写 → 通过

> **教师**：
> 老师，我重新写了：
> 1. 学生能绘制闭环温控系统的方框图（含给定值、控制器、执行器、被控对象、传感器、反馈通道 6 个节点），并能向同伴解释每个节点的物理含义；
> 2. 在 30℃ 阶跃干扰注入下，学生使用温度传感器测定系统稳态误差 ≤±1℃ 的调节时间；
> 3. 学生根据测得数据，撰写 200 字"干扰—偏差—反馈—校正"的因果自辩短文。

> **啄木鸟**：
> 通过。
>
> 三条目标全部具备：① 行为动词（绘制 / 解释 / 测定 / 撰写）；② 物理极限（30℃ 阶跃 / ≤±1℃ / 调节时间秒数）；③ 可观测证据（方框图、温度数据、短文）。本道防线已闭合。
>
> 请进入第二道防线：把"核心学习活动 + 随堂评价任务"贴上来。注意：教学评三元必须强映射到刚才三条目标——活动做的、评价测的，必须紧扣方框图、稳态误差、因果自辩三项中的至少一项。

## 5. 复用提示 (Reuse)

- 适用于所有出现"培养 / 提高 / 体验 / 理解"等不可观测动词的教学目标审计。
- 复盘时的关键诊断逻辑锚点：
  1. 是否含可观测行为动词？
  2. 是否含具体物理极限 / 工艺公差 / 量化阈值？
  3. 是否覆盖课标对应学业质量水平的核心行为？
