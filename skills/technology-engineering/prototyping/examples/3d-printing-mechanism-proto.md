# 案例：连杆机构零件的 3D 打印快速成型与装配实操

## 1. 输入数据 (Input)
```yaml
fabrication_method: FDM 3D 打印 + 手工扩孔装配
material_type: PLA 环保耗材
safety_level: 高温喷头防烫伤、模型铲刀安全使用指引
```

## 2. 成果展示
- **切片参数指导**：层高 0.2mm，填充率 25%（兼顾打印速度与机械强度），打印方向沿受力最大方向平铺以避免层间撕裂。
- **公差与配合**：销轴直径 4.0mm，孔径预留 4.2mm 间隙配合，使用铰刀或砂纸进行微调装配。
- **质检要点**：无明显拉丝、转角无翘曲、连杆旋转顺畅无卡顿。
