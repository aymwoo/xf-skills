# 案例：便携式折叠手机支架的结构与稳定性设计

## 1. 输入数据 (Input)
```yaml
design_topic: 适用于宿舍桌面与携带出行的多角度手机支架
design_domain: 结构与设计 (稳定状态、重心控制、铰接连接)
material_constraints: 3mm 椴木板、激光切割机、M3 螺栓与蝶形螺母
```

## 2. 教学任务设计
1. **需求与限制分析**：要求折叠后厚度小于 15mm，展开后支持 30°-75° 三档角度调节，承重不低于 300g。
2. **重心与支撑面分析**：探究结构倾覆的临界条件（重力线必须落在支撑底面多边形内部）。
3. **图样绘制**：绘制带尺寸标注的正等轴测草图与零件榫卯连接详图。
4. **方案权衡表**：从“便携性、调节灵活度、加工难度、结构牢固度”四个维度对三角形铰接方案与卡槽插接方案打分。
