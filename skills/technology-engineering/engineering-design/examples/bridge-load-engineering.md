# 案例：轻质高强桁架桥工程设计与载荷测试

## 1. 输入数据 (Input)
```yaml
engineering_challenge: 使用 50 根桐木条与白乳胶设计一座跨度 40cm、能承受 15kg 动载荷的轻量化桥梁
budget_and_material_limits: 桥体自重不得超过 80g，桥下预留 10cmx10cm 通航净空
quantifiable_metrics: 结构承重效率比 = 极限承载力(g) / 桥体自重(g)
```

## 2. 成果展示 (工程思维落地)
- **方案构思**：学生小组分别提出“华伦式桁架（Warren Truss）”、“普拉特式桁架（Pratt Truss）”与“下承式拱桥”三种构型。
- **Pugh 决策矩阵**：从“受压稳定性、节点抗剪强度、胶接施工便利性、材料用量”四项加权打分，最终确定优选方案。
- **失效分析**：加载至 12kg 时，跨中上弦杆发生欧拉失稳弯曲折断。学生团队提出迭代方案——将上弦杆改为双层胶合工字形截面以提升抗弯刚度。
