# 案例：智慧教室环境监测系统开发项目

## 1. 输入数据 (Input)
```yaml
project_name: 智慧教室多参数空气与光照监测系统
system_architecture: ESP32 + 温湿度/光敏传感器 + MQTT 协议 + Web 前端看板
project_periods: 6 课时
```

## 2. 成果推进阶段
- **第 1 课时 (需求分析)**：调研教室通风与采光痛点，绘制用户用例图。
- **第 2 课时 (硬件采集)**：编写 ESP32 传感器数据读取与串口打印程序。
- **第 3 课时 (网络通信)**：通过 Wi-Fi 将 JSON 格式数据上报至 MQTT Broker。
- **第 4 课时 (数据呈现)**：编写网页看板，实时刷新折线图并设置超标预警。
- **第 5 课时 (联调测试)**：进行 24 小时连续运行压力测试与排错。
- **第 6 课时 (路演答辩)**：向总务处老师展示汇报与使用建议。
