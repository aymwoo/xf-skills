# 案例：基于计算思维的“校园食堂排队优化”问题解决

## 1. 输入数据 (Input)
```yaml
problem_scenario: 中午放学后食堂窗口拥堵，排队时间超过 20 分钟
target_ct_dimension: 分解、抽象与算法设计
```

## 2. 成果展示 (思维外化过程)
- **分解 (Decomposition)**：将排队问题拆解为三个子环节：① 点餐耗时、② 刷卡结算耗时、③ 出餐打包耗时。
- **模式识别 (Pattern Recognition)**：观察发现 70% 的同学都集中点同一两款热门套餐；结算时由于找零钱/找校园卡造成停顿。
- **抽象 (Abstraction)**：忽略菜系口味等细节，将问题抽象为“排队论单队列多服务台模型（M/M/c）”。
- **算法设计 (Algorithm)**：设计分流算法策略——热门套餐开设专属直取通道，提前扫码预定，窗口直接核销取餐。
