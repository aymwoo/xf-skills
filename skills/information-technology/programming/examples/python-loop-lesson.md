# 案例：Python for 循环与累加求和教学设计

## 1. 输入数据 (Input)
```yaml
programming_language: Python 3
target_construct: for 循环结合 range() 实现累加求和
real_world_context: 微信步数排行榜周累计步数计算
ide_environment: IDLE / Thonny
```

## 2. PRIMM 教学环节设计示例
- **Predict (预测)**：展示一段带有 `print(step)` 的代码，让学生猜测输出结果。
- **Read (研读)**：学生圈出循环变量 `step` 和累加器 `total` 的初始值。
- **Investigate (探究)**：修改 `range(1, 8)` 为 `range(1, 101)`，观察计算结果的变化。
- **Modify (修改)**：将程序改造为“仅统计大于 10000 步的达标总天数”（引入分支与计数器）。
- **Make (创造)**：设计属于自己的“班级图书借阅总册数统计程序”。
