# 案例：基于真实气象数据的可视化分析

## 1. 输入数据 (Input)
```yaml
data_topic: 某城市近十年气温与降水量变化趋势分析
data_tool: Python (Pandas + Matplotlib)
dataset_description: 包含日期、最高温、最低温、降水量、风速的 CSV 表格
```

## 2. 成果展示
- **数据清洗**：引导学生识别缺失值（NaN）与异常值（如负数降水量），使用均值填补或剔除。
- **图表选择**：最高/最低温选用双折线图表现趋势；月降水量选用柱状图表现总量分布。
- **深层结论**：学生结合图表分析温室效应背景下的极端天气频率变化。
