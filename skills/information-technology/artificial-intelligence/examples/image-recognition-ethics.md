# 案例：图像识别模型训练与算法偏见探究

## 1. 输入数据 (Input)
```yaml
ai_topic: 基于卷积神经网络的“戴口罩/未戴口罩”分类模型训练
ai_tool_platform: 浏览器端轻量图像分类工具 (无需写深度学习代码)
ethics_focus: 训练集多样性不足导致不同肤色或光照下的识别偏见
```

## 2. 核心教学环节
1. **真实需求**：智慧校园门禁自动检测师生佩戴口罩情况。
2. **数据标注**：学生分两组采集“佩戴口罩”与“未戴口罩”各 50 张样本。
3. **模型训练**：点击训练并观察准确率曲线。
4. **攻防测试与伦理反思**：当用手捂住嘴巴时，模型是否误判为戴口罩？为什么？当光线变暗时准确率为何暴跌？引导学生认识到“训练数据的质量直接决定 AI 的公平与鲁棒性”。
