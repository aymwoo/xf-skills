# 案例：二分查找算法探究教学设计

## 1. 输入数据 (Input)
```yaml
algorithm_name: 二分查找 (折半查找)
grade_level: 高中一年级
visual_or_unplugged_activity: 1-100 猜商品价格互动游戏
data_scale_contrast: 对比 100万 条有序数据中顺序查找与二分查找的最大比较次数
```

## 2. 核心教学环节
1. **情境激趣**：猜 1-100 之间的神秘数字，每次回答“太大了”或“太小了”，学生发现从 50 开始猜只需最多 7 次。
2. **逻辑抽象**：归纳出 `left = 0`, `right = len(arr)-1`, `mid = (left + right) // 2` 的动态调整过程。
3. **边界陷阱**：讨论为什么当 `left > right` 时判定为“未找到”，以及循环条件为什么是 `left <= right`。
4. **效率震撼**：100万条数据，顺序查找最多需 1,000,000 次，而二分查找最多仅需 20 次！
