# 案例：课后教学反思与二次设计

## 1. 输入数据 (Input)
```yaml
original_lesson_plan: 初二《Python 循环结构之 while 循环》
classroom_observations: |
  1. 课堂导入生动，学生兴趣高；
  2. 但在自主编程阶段，近 40% 的学生忘记写计数器自增语句导致程序陷入死循环；
  3. 导致后续拓展任务时间严重不足，提前拖堂 3 分钟。
student_assessment_results: 随堂任务完成率仅 60%。
```

## 2. 成果展示 (反思要点)
- **归因诊断**：while 循环的“循环体内部状态改变”是纯逻辑隐蔽动作，初学者容易遗忘。教师在讲解时过于强调条件判断，忽视了循环变量更新的可视化表征。
- **改进行动项**：
  1. 引入“程序单步调试运行追踪表”，让学生在草稿纸上手动模拟变量变化过程；
  2. 课前增加 1 分钟“找茬游戏”：展示包含死循环的代码片段，让学生主动发现缺少更新语句的危害。
