# 问卷星导入文本转换专家 (WJX Survey Converter)

## 技能说明
面向各类学术问卷、德尔菲法专家函询问卷及评价量规的问卷星（WJX）导入文本标准化转换工具。

## 目录结构
- `SKILL.md`：核心定义与执行 SOP。
- `references/wjx_syntax_reference.md`：问卷星文本导入全题型语法手册。
- `references/delphi_survey_guide.md`：德尔菲法问卷设计与统计分析（均值、变异系数）指南。
- `scripts/parse_docx.py`：无外部依赖的 Word (.docx) 问卷解析脚本。
- `examples/`：输入输出转换样例。

## 触发词
`问卷星导入`、`问卷星`、`问卷转换`、`矩阵题`、`矩阵量表题`、`比重题`、`德尔菲问卷`、`函询问卷`、`Word转问卷星`、`WJX`
