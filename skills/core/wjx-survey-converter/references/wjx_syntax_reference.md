# 问卷星（WJX）文本导入语法与格式参考规范

本文档整理自问卷星官方帮助中心（Help 138 / 160 / 168 / Catid 58），为文本创建问卷提供标准格式参考。

---

## 1. 基础排版原则

1. **题目分界**：每道题之间必须**空一行**（回车换行），便于问卷星解析器准确识别题目边界。
2. **题号标识**：题干必须以数字标号开头，例如 `1.`、`2、`、`16.` 等。
3. **主标题识别**：文档第一行若无题号与标签，问卷星会自动将其识别为问卷主标题。
4. **选项排布**：单选、多选题的选项通常每行一个，也可以带有 `A.`、`B.`、`C.` 或纯文本。

---

## 2. 核心题型语法速查表

| 题型名称 | 语法标签 | 核心特征与文本排版结构 |
| :--- | :--- | :--- |
| **单选题** | 无标签 或 `[单选题]` | 题干单独一行；下方紧跟各选项，每行一项 |
| **多选题** | `[多选题]` | 题干末尾加 `[多选题]`；下方紧跟各选项，每行一项 |
| **填空题 / 简答题** | 无标签 或含 `____` | 题干单独一行，下方无选项直接接空行；或题干中包含下划线 |
| **多项填空题** | 无特殊标签 | 题干中使用至少 4 个下划线 `____` 标记每个填空位 |
| **矩阵单选题** | `[矩阵题]` | 题干加 `[矩阵题]`；第 2 行为列选项（空格分隔）；第 3 行起为行标题 |
| **矩阵量表题** | `[矩阵量表题]` | 题干加 `[矩阵量表题]`；第 2 行为分值刻度（空格分隔）；第 3 行起为行标题 |
| **表格题（下拉框）** | `[表格题]` | 题干加 `[表格题]`；第 2 行为选项；第 3 行为列标题；第 4 行起为行标题 |
| **比重题** | `[比重题]` | 题干加 `[比重题]`；下方每行一个待分配权重的项目 |
| **排序题** | `[排序题]` | 题干加 `[排序题]`；下方每行一个待排序项目 |
| **段落说明** | `[段落说明]` | 标题加 `[段落说明]`；下方为说明正文；不作为题目计分 |

## 3. 各题型标准文本示例

### 3.1 单选题 (Single Choice)
```text
1. 您的最高学历是？
大专及以下
本科
硕士研究生
博士研究生
```

### 3.2 多选题 (Multiple Choice)
```text
2. 您在日常教学中经常使用哪些数字资源？[多选题]
多媒体课件与动画
仿真模拟软件
数字化传感器（DIS）
在线题库与测评系统
其他
```

### 3.3 矩阵单选题 (Matrix Single Choice)
适用于：多项指标在同一组固定评价等级（如：大/中/小，经常/偶尔/从不）下打分。
```text
3. 您对指标体系评价的主要判断依据及影响程度：[矩阵题]
影响程度大 影响程度中 影响程度小
理论分析（对相关理论的掌握与运用）
实践经验（从事相关领域的实践经验）
同行了解（对国内外研究现状的了解）
直觉判断
```

### 3.4 矩阵量表题 (Matrix Rating Scale)
适用于：德尔菲专家咨询指标重要性、可行性评分，或满意度、态度量表（自动在问卷星后台计算每行均值 Mean 与变异系数）。
```text
4. 一级指标重要性评分（5分为非常重要，1分为很不重要）：[矩阵量表题]
5 4 3 2 1
1. 政策与保障
2. 过程与实施
3. 成果与素养
4. 身份与认同
```
*注：第 2 行可写 `5 4 3 2 1` 或 `1 2 3 4 5`。若需显示文字描述，可在题干中注明含义，问卷星量表题以数字分值统计最优。*

### 3.5 比重题 (Proportion Question)
适用于：权重分配、预算分配、精力占比等总和须为 100% 的题目。
```text
5. 请填写各维度的建议权重（四个维度合计须为100%）：[比重题]
政策与保障（建议区间：10%—15%）
过程与实施（建议区间：30%—40%）
成果与素养（建议区间：25%—30%）
身份与认同（建议区间：10%—15%）
```

### 3.6 表格下拉题 (Table Question)
适用于：多行多列且每个单元格需要从固定选项中下拉选择。
```text
6. 请对以下产品各维度进行综合评价：[表格题]
差 一般 良好 优秀
性能 外观 稳定性 售后
产品A
产品B
```
*说明：第 2 行是所有下拉框的选项（空格分隔）；第 3 行是表格的列标题；第 4 行起为表格的行标题。*

### 3.7 填空题与多项填空题 (Fill-in)
```text
7. 您对本次指标体系有何整体建议？

8. 请填写您的单位：________，职务：________，教龄：________年。
```

### 3.8 排序题 (Ranking Question)
```text
9. 请按照您认为的重要程度对以下要素排序：[排序题]
课堂互动深度
项目真实性
过程性证据留存
跨学科整合度
```

### 3.9 段落说明 (Paragraph / Instructions)
用于模块说明、填答指南或背景资料附录。
```text
第一部分 问卷前言与填答说明[段落说明]
尊敬的专家：您好！感谢您参与本次课题函询。本问卷预计耗时20分钟，所有数据仅用于群体统计分析...
```

## 4. 导入时常见错误与避坑指南

1. **标签格式错误**：标签必须使用中文中括号或英文方括号，如 `[矩阵量表题]`，标签与题干之间不要有特殊不可见字符。
2. **矩阵题缺少列选项行**：矩阵题题干下一行必须紧跟用**空格**隔开的列标题列表，不可直接写行标题。
3. **题目粘连**：两道题之间若没有空行，问卷星解析器可能会将下一题题干误识别为上一题的选项。
4. **比重题总和校验**：导入后需在问卷星后台题目的高级设置中，确认开启“总和限制为 100%”开关。
