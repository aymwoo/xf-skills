# 案例：小组合作探究任务单设计

## 1. 输入数据 (Input)
```yaml
learning_objective: 比较不同绝热材料的保温性能
activity_type: 4人小组合作探究
duration: 15分钟
group_size: 4
scaffolding_level: 中等支架（提供数据记录表格与对照实验提示）
```

## 2. 成果展示
- 分工机制：1号温度记录员、2号材料操作员、3号计时员、4号图表绘制与发言人。
- 引导提示：控制变量法提示（相同的热水初温、相同的水量、相同的时间间隔）。
- 评价标准：5分钟内完成数据记录，10分钟内得出初步折线图趋势。
