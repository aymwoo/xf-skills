# 案例：校园节水节能改造项目式学习

## 1. 输入数据 (Input)
```yaml
project_theme: 校园洗手池水资源回收与自动灌溉系统
total_periods: 6课时
target_grades: 高中一年级
interdisciplinary_links: 物理 (流体力学/电路)、通用技术 (结构与控制)、生物 (植物生理)
```

## 2. 成果展示
- **驱动性问题**：我们如何为学校设计一套低成本、防堵塞的雨水与废水循环灌溉装置，解决绿化带定点灌溉问题？
- **阶段里程碑**：
  - 第 1-2 课时：入项调查与校园用水测算。
  - 第 3-4 课时：方案设计与微型管路系统搭建。
  - 第 5-6 课时：现场部署测试、数据比对与全校路演答辩。
