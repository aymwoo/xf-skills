# 案例：课中形成性评价（出门条）设计

## 1. 输入数据 (Input)
```yaml
target_competencies: 能正确区分循环结构中的 while 循环与 for 循环适用场景
assessment_stage: 课中形成性评价 (Exit Ticket)
assessment_format: 2道情境选择题 + 1道简答思考
```

## 2. 成果展示
- 题目 1（情境选择）：已知班级有 45 位同学需要逐一录入成绩，请问最适合使用哪种循环？（考察循环次数已知情境）
- 题目 2（情境选择）：让用户反复猜数字直到猜中为止，最适合使用哪种循环？（考察条件控制循环情境）
- 诊断分析：若学生选错题目 2，说明未建立“先判定后执行”的条件思维，需提供条件分支复习卡片。
