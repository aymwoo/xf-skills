# 案例：通用教学设计样例

## 1. 输入数据 (Input)
```yaml
topic: 探究光的折射规律
grade_level: 八年级 (初中二年级)
duration: 45分钟
student_prior_knowledge: 已掌握光的直线传播与光的反射定律，会使用量角器
teaching_environment: 物理数字化探究实验室
```

## 2. 规范输出预览 (Output Preview)
- 教学目标：通过实验观察光从空气斜射入水中时的偏折现象，能用自己的语言表述折射角与入射角的关系。
- 导入设计：筷子在水中的“折断”魔术引出认知冲突。
- 探究活动：分组使用激光笔与半圆形玻璃砖进行定量测量。
- 评价设计：观察学生记录数据的规范性及折射光路图的绘制准确率。
