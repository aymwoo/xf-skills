# 案例：科学探究实验报告评价量规

## 1. 输入数据 (Input)
```yaml
task_description: 撰写一份关于水质酸碱度检测的实验探究报告
evaluation_dimensions:
  - 实验假设与方案设计 (30%)
  - 数据采集与误差分析 (30%)
  - 结论推导与科学论证 (20%)
  - 报告排版与图表规范 (20%)
levels_count: 4 (优秀、良好、合格、待改进)
```

## 2. 成果展示 (维度示例)
- **实验假设与方案设计 (优秀)**：明确提出可检验的假设；变量控制严密；详述仪器使用与安全防范步骤。
- **数据采集与误差分析 (良好)**：数据记录完整规范；能指明主要误差来源，但未给出具体减小误差的定量估算。
