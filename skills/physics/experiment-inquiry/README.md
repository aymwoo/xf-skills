# physics.experiment-inquiry: 高中物理数字化实验探究教学设计

## 1. 技能定位与核心价值

`physics.experiment-inquiry` 是专为高中物理教师打造的数字化实验探究教学设计技能。
它以普通高中物理课程标准为指引，深度融合 **DIS 数字化实验系统（数字化信息系统，Digital Information System）**，包括力传感器、光电门、位移传感器、电流/微安传感器与数据拟合软件。

本技能的核心价值在于：
- **拒绝“照方抓药式”传统做实验**：打破学生只按指导书步骤连线读数的机械劳动，将重心前移至“控制变量猜想”与后移至“图象拟合与误差归因”；
- **赋能跨学科 STEM 联通**：将物理学中的力学、电学瞬时数据采集与通用技术（工程受力结构）、信息科技（传感器数据处理与算法拟合）紧密咬合。

---

## 2. 探究教学六步标准工作流

1. **真实情境问题提炼 (Contextual Phenomenon)**：从生活或工程实际中提炼力学/电学探究问题；
2. **物理假说与控制变量 (Hypothesis & Variables)**：明确自变量、因变量与无关变量；
3. **DIS 传感方案设计 (Sensor Configuration)**：选择合适的力/光电门/位移传感器，合理布置采样频率；
4. **动态数据采集推演 (Data Acquisition)**：记录原始数据表与实时曲线；
5. **坐标图象拟合反思 (Image Analysis & Fitting)**：分析图象斜率、截距与拐点的物理意义；
6. **理想条件偏离与误差归因 (Error Attribution)**：深入反思空气阻力、摩擦损耗与仪器系统误差。
