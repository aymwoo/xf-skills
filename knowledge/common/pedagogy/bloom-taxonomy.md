# 布鲁姆教育目标分类学 (修订版) (Bloom's Taxonomy Revised)

## 1. 核心定义与内涵
布鲁姆教育目标认知领域（Anderson & Krathwohl 2001 修订版）将认知过程由低到高划分为六个层级，是教学目标制定、任务设计与评价分级的核心参照基准：

| 认知层级 | 核心定义 | 典型行为动词 |
| :--- | :--- | :--- |
| **1. 记忆 (Remember)** | 识别和回忆相关知识事实、术语与基本概念 | 识别、列举、回忆、命名、匹配、复述 |
| **2. 理解 (Understand)** | 从口头、书面和图形等教学信息中构建意义 | 解释、举例、分类、总结、推断、比较、说明 |
| **3. 应用 (Apply)** | 在给定的情境中执行或使用某一程序或算法 | 执行、实施、计算、使用、演示、操作、求解 |
| **4. 分析 (Analyze)** | 将材料分解为其组成部分，确定部分之间及与总体结构的关系 | 区分、组织、归因、对比、解构、辨析、排错 |
| **5. 评价 (Evaluate)** | 基于准则和标准作出判断与决策 | 检查、评判、权衡、论证、批判、检验、衡量 |
| **6. 创造 (Create)** | 将各要素组合成一个连贯的整体，或重组成新的结构 | 生成、规划、产出、设计、构建、发明、重构 |

---

## 2. 教学转化与认知阶梯建议
- **低阶认知向高阶认知跃迁**：一堂好课应避免长时间停留在记忆与理解层级，应通过驱动性问题与探究活动引导学生跃迁至分析、评价与创造层级。
- **目标书写规范**：目标陈述句式推荐为：“学生能够通过【具体学习活动/工具】，【行为动词】+【学习内容】，达到【质量标准】。”
