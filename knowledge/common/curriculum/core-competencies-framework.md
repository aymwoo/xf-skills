# 基础教育核心素养通用框架 (Core Competencies Framework)

## 1. 核心素养内涵
中国基础教育课程改革强调以“核心素养（Core Competencies）”为纲，强调学生在面对复杂、不确定真实情境时所表现出的**必备品格与关键能力**。

## 2. 三维目标与核心素养的深化演进
- **双基时代**：基础知识 + 基本技能。
- **三维目标时代**：知识与技能 + 过程与方法 + 情感态度与价值观。
- **核心素养时代**：在真实情境中综合运用跨学科知识、高阶思维、价值观念解决复杂问题的综合素养。

## 3. 教学设计落点
- **真实情境（Authentic Context）**：拒绝纯符号推演，将教学置于学生身边的生活问题或社会工程挑战中。
- **大观念与大单元（Big Ideas & Units）**：围绕学科本质的大概念组织结构化单元学习。
- **教-学-评一体化（Alignment）**：目标、教学活动与评价标准高度对齐。
