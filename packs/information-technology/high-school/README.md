# 高中信息科技教学 Skill Pack (High School IT Pack)

## 组合包说明
本 Pack 汇集了高中信息科技必修（《数据与计算》、《信息系统与社会》）与选择性必修模块所需的全部教学 AI 技能。

## 包含能力
- **通用教学底层**：教案设计、活动设计、评价与量规、PBL 与课后反思。
- **信息科技学科专项**：
  - 编程教学 (Python/C++) 与 PRIMM 支架 (`it.programming`)
  - 查找排序算法探究 (`it.algorithm`)
  - 数据清洗与图表分析 (`it.data`)
  - 人工智能与伦理思辨 (`it.artificial-intelligence`)
  - 计算思维四维度培养 (`it.computational-thinking`)
  - 软硬件融合大单元项目 (`it.project-learning`)
